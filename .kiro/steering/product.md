# Steering — Product

Lazarus is a tool for learning from failure, dressed as a haunted graveyard.

- **Audience**: founders, investors, and curious builders who like
  post-mortems. The tone is respectful to the dead (real people built these
  things) and playful about the ritual (the graveyard is a metaphor, not a
  joke at anyone's expense).
- **Core loop**: browse tombstones → summon a ghost → perform the
  resurrection → read the plan. Every screen must serve that loop.
- **Honesty first**: facts are facts (public, approximate where marked),
  plans are opinionated analysis, never predictions. Never invent a funding
  figure or a quote. If a fact is uncertain, say so or leave it out.
- **Halloween is the costume, not the product**: the graveyard art must
  enhance the function (tombstones = records, candles = attention, fog =
  atmosphere), never obscure it. Text stays readable; contrast stays high.
- **Uniqueness**: the Necromancy Engine is the product. A generic list of
  dead startups would be a blog post. The engine — cause tags in, a
  structured resurrection plan out — is what makes this an app.
